# neon-eternum-frontera-cuantica
NEON ETERNUM: FRONTERA CUÁNTICA es una experiencia de videojuego narrativo interactivo de última generación ambientada en el planeta Eternum. Incluye mundo abierto, facciones, misiones dinámicas, combate táctico, cibernéticos, economía, clima, NPC con memoria, consecuencias persistentes y una interfaz diegética.
